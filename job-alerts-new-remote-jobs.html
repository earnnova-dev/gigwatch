The no-auth recipe: alert yourself on new postings

Two moving parts: a stable job id so you can tell "new" from "already seen," and a feed that returns all boards in one call. The GigWatch API gives you both. Here's the whole thing:

GET https://remote-jobs-api.tten.no/v1/jobs?limit=500

Run it on a schedule (cron, GitHub Actions, or a 60-second loop), keep a small file of the job ids you've already seen, and alert on anything new:

import json, urllib.request, datetime, smtplib

FEED = "https://remote-jobs-api.tten.no/v1/jobs?limit=500"
SEEN = "seen_ids.json"

def fetch():
    req = urllib.request.Request(FEED, headers={"User-Agent": "job-alert/1.0"})
    d = json.load(urllib.request.urlopen(req, timeout=30))
    jobs = d.get("jobs", d)
    return [j for j in jobs if j.get("id")]

def load_seen():
    try: return set(json.load(open(SEEN)))
    except FileNotFoundError: return set()

def main():
    new = [j for j in fetch() if j["id"] not in load_seen()]
    if new:
        lines = "\n".join(
            f"- {j['title']} @ {j.get('company','?')}  [{j.get('source','?')}]\n  {j.get('url','')}"
            for j in new[:25])
        # send to your email / Slack / Telegram / webhook here
        print(f"{len(new)} new job(s):")
        print(lines)
    json.dump(sorted(load_seen() | {j['id'] for j in fetch()}), open(SEEN, "w"))

if __name__ == "__main__":
    main()
Two details that make this reliable. (1) Dedup on the id field, not the title — titles collide across boards, ids don't. (2) Persist seen_ids.json between runs so a posting that stays up for days alerts you exactly once. Filter to source=jobicy or skills=python in the query if you only want a slice of the feed.

What to alert on

Once you're getting new postings, rank them by freshness and fit:

  • Recency first. A job posted hours ago is where the applicant pool is thinnest. The feed's published field lets you sort new ones to the top.
  • Board matters. Per the table above, Jobicy and We Work Remotely carry ~89% of the fresh signal right now — if you only alert on one, alert on those two.
  • Skills, not just title. The feed supports skills=python,backend so a "python" posting on an ops board doesn't spam you. Match the criteria to what you'd actually apply for.
