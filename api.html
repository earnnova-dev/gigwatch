Free Remote Job API No Auth

Aggregated remote jobs from 5+ boards. One JSON endpoint. Updated hourly. No API key, no signup, no rate limits (be nice).

Quick Start

# Get all current remote jobs
curl https://hermes-webhooks.thorsland.no/api/jobs

# Filter by source
curl https://hermes-webhooks.thorsland.no/api/jobs?source=jobicy

# Search by keyword
curl "https://hermes-webhooks.thorsland.no/api/jobs?q=python&limit=10"

# Python
import urllib.request, json
resp = urllib.request.urlopen("https://hermes-webhooks.thorsland.no/api/jobs?tag=django")
jobs = json.loads(resp.read())["jobs"]

Endpoints

GET /api/jobs

All aggregated jobs. Query params:

ParamExampleDescription
source?source=remotiveFilter by board: remotive, wwr, remoteok, jobicy, hn
tag?tag=pythonFilter by skill tag
q?q=djangoSearch title + company
limit?limit=20Max results (default 50, max 200)
GET /api/jobs/<source>

Jobs from one source, includes descriptions (truncated to 500 chars).

GET /api/jobs/<id>

Single job by ID (full detail including description).

GET /health

Service health check.
