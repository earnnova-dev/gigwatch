Remote Job API: one endpoint for every remote job board

A remote job API returns structured, machine-readable job data from remote job boards as JSON. Instead of scraping 5+ sites with brittle HTML selectors, you call an endpoint and get a normalized feed you can filter by location, salary, and source. Below: the 5 major remote-job data sources that actually work in 2026, what each gives you, and a single endpoint that returns all five at once.

Why use a remote job API (vs. scraping)

  • Stability. Job boards change their HTML and block scrapers constantly; a feed endpoint with a stable schema does not.
  • Normalization. Each board uses different field names for salary, location, and tags. A good API gives you one consistent shape.
  • Speed. One request returns the whole feed; no per-board pagination, retries, or rate-limit juggling.
  • Filtering. Query params like location, min_salary, and source let you narrow server-side instead of post-processing.

Get all 5 in one call: Remote Jobs API

If you would rather not wire up and maintain five separate feeds, Remote Jobs API returns all of the above through a single normalized endpoint. It is live right now, no scraping, and the free tier needs no API key.

The endpoint is in open mode, so this works immediately:

curl "https://remote-jobs-api.tten.no/v1/jobs?limit=3"

Filter server-side

Query params narrow the feed before it is returned, so you do not post-process thousands of rows:

# Only remote engineering roles in Germany, min salary 80k
curl "https://remote-jobs-api.tten.no/v1/jobs?location=germany&min_salary=80000&limit=20"

# Only Remotive listings
curl "https://remote-jobs-api.tten.no/v1/jobs?source=remotive"

# Count how many match (open-mode, no key needed)
curl "https://remote-jobs-api.tten.no/v1/jobs?location=spain&min_salary=60000"

In Python

import requests

r = requests.get(
    "https://remote-jobs-api.tten.no/v1/jobs",
    params={"location": "remote", "min_salary": 70000, "limit": 50},
    timeout=20,
)
for job in r.json()["jobs"]:
    print(job["title"], job["company"], job["salary"], job["source"])
