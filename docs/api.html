Remote Jobs API Free tier

Live, normalized remote jobs from 5 boards — one clean endpoint, one schema. Free tier: 100 calls/month, no card. Self-hostable (MIT) for free.

How it works: a free API key gets you 100 calls/month across all five boards. Request one at earnnova@tten.no (say the skills/boards you need and you'll get a key back), or run the whole engine yourself with remote-jobs-api — stdlib-only Python, MIT licensed, free.

Quick start

# Health + live job count (public, no key)
curl https://remote-jobs-api.tten.no/health
# -> {"status":"ok","sources":["remotive","remoteok","jobicy","wwr","hn"],"count_live":323}

# Available boards (public, no key)
curl https://remote-jobs-api.tten.no/v1/jobs/sources
# -> {"sources":["remotive","remoteok","jobicy","wwr","hn"]}

# Normalized jobs (needs your free key)
curl -H "Authorization: Bearer <YOUR_KEY>" \
     "https://remote-jobs-api.tten.no/v1/jobs?skills=python,backend&limit=5"

# Python
import urllib.request, json
req = urllib.request.Request(
    "https://remote-jobs-api.tten.no/v1/jobs?skills=python&limit=10",
    headers={"Authorization": "Bearer YOUR_KEY"})
jobs = json.loads(urllib.request.urlopen(req).read())["jobs"]

Endpoints

GET /health

Public. Service status, the list of boards, and the current live job count.

GET /v1/jobs/sources

Public. The set of supported boards: remotive, remoteok, jobicy, wwr, hn.

GET /v1/jobs

Keyed (free tier included). A deduped, normalized list of remote jobs. Every board uses the same schema, so no per-board parsing on your side. Query params:

ParamExampleDescription
skills?skills=python,backend,apiKeywords to match and rank by — adds a deterministic 0–100 fit_score and ranks best-fit first
source?source=jobicyRestrict to one board: remotive / remoteok / jobicy / wwr / hn
limit?limit=20Max results (default 50, max 500)
min_score?min_score=70Only jobs with fit_score ≥ this (needs skills)
format?format=csvjson (default) or csv (Pro tier)

Response format

One normalized job object, regardless of source. published is always a canonical ISO-8601 UTC string.

{
  "count": 1,
  "generated_at": 1790433192,
  "query": { "skills": ["python", "api"], "source": null, "min_score": null, "limit": 1 },
  "jobs": [

      "id": "94516b10164d3c70",
