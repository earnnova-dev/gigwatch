Which one should you use?

"I need clean structured JSON with salary." → Remotive

Verdict: Remotive. It's the only no-auth source that consistently returns salary, contract type, and a stable JSON shape. remotive.com/api/remote-jobs?limit=50 — no key, no rate-limit wall for reasonable polling. This is the best single-source starting point.

"I want the most remote-only job volume." → We Work Remotely

Verdict: We Work Remotely. The largest remote-only board. It's RSS, not JSON, so you parse the feed — but the coverage (dev, design, marketing, sales) is unmatched. Use weworkremotely.com/remote-jobs.rss and a feed parser; expect fewer structured fields than Remotive.

"I want broadest coverage in a single call." → Jobicy

Verdict: Jobicy. It aggregates 50+ boards into one JSON endpoint with industry, level, and geo. The trade-off is freshness (updated roughly daily) and looser schema. jobicy.com/api/v2/remote-jobs?count=50 is the cheapest way to get a wide net in one request.

"I want raw startup hiring signals." → Hacker News

Verdict: HN (via Algolia). Search hn.algolia.com/api/v1/search?query=hiring&tags=story and filter by date/points. Best for catching startup "we're hiring" posts that never hit job boards. No structured fields — it's raw post data, so treat it as a signal source, not a structured feed.

"I'm building a job alert / monitoring tool." → Don't pick one — combine

Verdict: Combine. No single source covers enough. Remotive + Jobicy + WWR gives you structured data + volume + aggregator breadth. The catch: the same job appears on multiple aggregators, so you must dedupe on normalized title + company. Trade-offs every build hits

ConcernWhat you'll actually seeHow to handle it
Free tier ≠ SLAThese are public marketing endpoints, not contracted APIs. No uptime guarantee.Cache 15–60 min; don't poll on a tight timer.
BlockingSome boards block the default python-requests User-Agent.Send a browser-like UA. If you get 403s, back off.
DuplicatesAggregators (Jobicy) repost the same job from upstream boards.Normalize title + company; key your store on that.
Sparse salaryOnly Remotive + a few aggregators publish it; most don't.Don't build ranking on salary alone — treat it as optional.
Freshness mismatchJSON APIs are near-real-time; RSS/aggregators are daily.Blend sources; label each job with its source + timestamp.

Free-key tiers (one registration, more volume)

If you outgrow the no-auth set, Adzuna (250 req/day free) and Jooble (free key, multi-board) add scale for the cost of an email. Both require a key, so they're a step past the no-auth tier above.

What "no clean API" boards mean

JustRemote is a Next.js SPA (its /api/jobs returns an HTML shell) and Arc.dev sits behind Cloudflare that blocks non-browser UAs. If a board needs a real browser to render, treat it as a scraping problem, not an API problem — or cover it with an aggregator that already has it.
